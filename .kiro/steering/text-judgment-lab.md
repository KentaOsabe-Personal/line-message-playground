# 文章判定ラボの境界と判定契約

本人向け LINE ミニアプリの文章判定ラボについて、認証、Jev 通信、文章判定、書き換え比較、画面寿命の設計・変更・検証に適用します。管理画面の owner session、LINE 配信、Webhook の契約は [line-integration.md](line-integration.md) に従います。

## 独立した本人認証

ラボの入口は `/liff/labs/text-judgment`、API は `/api/labs/text-judgment/` 配下です。専用 LIFF ID と Mini App channel ID を使います。共通の LIFF adapter を再利用しても、ラボの認証を管理画面の session に置き換えません。

Frontend は ID token をページ内メモリで扱い、API へ `Authorization: Bearer ...` で送ります。cookie は `credentials: 'omit'` で送らず、cache を無効にし、redirect に追従しません。token を URL、storage、画面、通常ログへ保存しません。

Backend は設定済みの HTTPS origin との完全一致を外部通信より先に確認します。ID token は LINE の検証 API へ一回だけ送り、issuer、audience、有効期限、subject を検証した後、`SHA-256("<aud>:<sub>")` をラボ専用の本人 digest と照合します。管理画面の allowlist digest は流用しません。

ラボは既定で無効です。有効化しても設定不備、未対応モデル、`DEBUG=true` では利用を拒否します。Jev API key と本人 digest は Backend の環境変数へ隔離し、エラーや設定型の表示から秘密値を返しません。

## 独立した文章判定

現在の API 契約は `contractVersion: 3` と `text` だけを受け取り、1〜1,000文字の非空自由文を判定します。比較元、過去の文章、identity、会話履歴は Jev の入力へ含めません。文章中の命令も判定対象として扱います。

固定モデルは `jev-1.13.0`、固定質問は分類（Choice）、感情（Score）、急ぎの要望（Noul）の3つです。分類は質問・依頼・報告・その他、感情は0〜2、急ぎの要望は0〜1を扱います。Backend は返却モデルが設定と一致することを確認します。Backend と Frontend の境界で形、有限な数値範囲、確率分布等を検証し、不正応答は安全な失敗へ変換します。採用閾値による補正やモデル fallback は行いません。

Frontend は値をモデルの判定として表示し、丸めは表示上に限定します。応答時間、モデル、未丸めの返却値を確認できるようにし、正解率、文章の優劣、判定理由を推測しません。

## 外部通信と利用制限

Jev への一回の HTTP 通信は Backend の gateway が所有し、全体の deadline と応答サイズ上限を設けます。429、失敗、タイムアウト、redirect、不正応答で自動再試行や別モデルへの切替を行いません。判定前後に利用資格の有効期限を確認します。

現在の利用制限は Backend プロセス内で本人ごとに同時1件、60秒間に開始10件です。この制限は複数プロセスでの共有や永続的な利用量管理には対応しません。Frontend も同期的な guard で連打を抑止し、15秒で待機を終了します。

## 書き換え比較と画面寿命

判定成功済みの文章と結果を独立した snapshot として固定し、書き換え後だけを既存 API で判定します。比較元の再判定や比較専用 API は追加しません。非空の入力を置き換えるときは確認し、比較をやめるときは入力を残します。判定待ち中は編集、比較元の切替、比較の中止、追加送信を受け付けません。

成功した比較は元の文章と書き換え後を一組で表示し、両側の結果を次の比較元として選べます。失敗時は送信時の入力と比較元を保持し、手動再送を待ちます。状態遷移は純粋な state module、通信・期限・画面寿命は hook、表示と入力操作は Component が担当します。

文章、比較元、編集中の入力、結果はページ内メモリだけに保持し、URL、storage、DB、共有 store、通常ログへ保存しません。利用資格の再確認中、失効、確認不可では画面が存続する間のデータを読取専用で保ち、再許可後も明示的な送信を待ちます。再読み込み、画面離脱、文書遷移を伴う再認証では消去します。

タイムアウト、資格喪失、画面離脱で待機中の通信を無効化し、timer と AbortController を後片付けします。abort が無視されても、操作 ID、画面存続、現在の利用資格、経過時間を完了時に確認し、古い応答から入力や結果を上書きしません。取り消せない LINE 配信操作の追跡とは別の寿命です。
